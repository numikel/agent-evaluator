### Added
- Resource list pages for personas, scenarios, rubrics and targets: name/description/updated table, inline delete confirmation, "New from template" (slug prompt → editor pre-filled from `GET /api/templates/:kind`), template download links (`download` attribute) and file upload (read → `POST /api/validate` → `PUT` raw text).
- Split **form ⇄ source** editors kept in sync in both directions (the file text is the single source of truth; form edits re-serialise it): persona (frontmatter form + Markdown body with section hints), scenario (goal/intent/success criteria/max turns/examples/expected artifacts + YAML), rubric (criteria list with type-specific fields, add/remove/retype, live weighted-score preview using the judge's aggregation incl. the built-in `goal_reached`), target (URL/hints/timeouts/viewport/auth env-var names) and evaluator (principles, max images, default rubric select, evidence selection).
- Validation on blur and before save through `POST /api/validate`; issues shown inline next to the field (`aria-invalid` + `aria-describedby`) and in an issues summary; saving sends the raw text so hand-written YAML comments survive; unsaved changes warn on page unload.
- Settings page: per role (`simulator`, `judge`, `evidence_selector`) a provider → model → effort cascade fed by `GET /api/providers` (configured only) and `GET /api/providers/:id/models` with refresh, a "fallback list" notice and a model card (context window, max output, images, reasoning); optional temperature; browser headless/slow-mo, concurrency and runs dir; `browser_installed` warning with the install command; empty state explaining env vars and vault options with a link to README "Secrets".
- Pure, unit-tested conversion helpers in `ui/src/editors/` (YAML and persona codecs, list helpers, issue mapping, rubric preview, settings draft, template naming) and `useDocumentEditor` / `useAsync` hooks.

### Changed
- API client: `api.putText` (raw text PUT), `endpoints.saveResourceText`, `endpoints.saveEvaluatorText`, `endpoints.template`, `endpoints.providerModels(id, { refresh })`.
- msw mocks mirror the server more closely: resource PUTs accept raw text and answer 204, persona issues are reported under `frontmatter.*`, `GET /api/providers` lists configured providers only, fixtures include a fallback-list provider and an unconfigured one.
